# 如何解除孕妇便秘之苦？

> 更新时间：2026-09-16 (UTC+8)

便秘是孕妇的常见病,一般发生在怀孕4~5个月后.孕妇便秘不可乱用泻药,否则会引起流产、早产。

引起孕妇便秘的原因怀孕时激素分泌使肠道肌肉松弛、肠蠕动减慢、运动量少,容易造成便秘.在内分泌激素变化的影响下，胎盘分泌大量孕激素，使胃酸分泌减少、胃肠道的肌肉张力下降及肌肉的蠕动能力减弱。这样，就使吃进去的食物在胃肠道停留的时间加长，不能像孕前那样正常排出体外。解除孕妇便秘之苦有6招：

1. 养成定时排便的习惯

每天早上和每次进餐后最容易出现便意。因此，起床后先空腹饮一杯凉开水或蜂蜜水，再吃好早餐，促进起床后的直立反射和胃结肠反射。这样，很快就会产生便意，长期坚持就会形成早晨排便的好习惯。其中以早上醒来排便最好。　

2. 产生便意后及时入厕

一有便意就要及时入厕，切不可形成忍便的习惯，这样非常容易导致便秘发生。排便时要保持放松的心态，即使未排出也不要心里紧张，否则便秘会更加重。

3. 多吃促进排便的食物

富含粗纤维素的瓜果、绿叶根茎蔬菜以及谷薯类，如苹果、香蕉、梨、葡萄、菠菜、海带、黄瓜、芹菜、韭菜、白菜、红薯、玉米等，可以促进肠道的肌肉蠕动，软化粪便，从而起到润肠滑便的作用，帮助孕妇排便。西梅中含有大量的膳食纤维，可以有效的解决孕期便秘的情况，对于孕妇是安全温和的。

4. 多饮水

每天注意饮水，但要掌握饮水的技巧，否则即使喝了水也不一定有什么效果。比如，每天在固定的时间里饮水，要大口大口地饮但不是暴饮，使水尽快到达结肠，而不是很快被肠道吸收到血液。这样，就可使粪便变得松软，容易排出体外。

5. 每天坚持活动身体

孕晚期时，很多孕妇常会因身体逐渐笨重而懒于活动，所以便秘现象在怀孕晚期更为明显。而适量的运动可以增强孕妇的腹肌收缩力，促进肠道蠕动，预防或减轻便秘。因此，孕妇即使在身体日益沉重时，也应该做一些身体力所能及的运动，如散步等，以增加肠道的排便动力。

6. 保持身心愉悦的生活

不要让身体太疲劳，每天早起早睡，充分休息，保持良好的精神状态，这样都有预防便秘的作用。情绪不佳时欣赏一下音乐，看看书刊等，转移一下注意力，烦躁也会导致便秘。生活中避免久站或久坐，也有利于防治便秘。
