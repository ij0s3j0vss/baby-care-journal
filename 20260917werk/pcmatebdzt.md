# 上海新华医院告患者及家属书

> 更新时间：2026-09-17 (UTC+8)

**尊敬的各位病友及家属：**

      你们好！

     为积极应对新型冠状病毒感染肺炎疫情，落实各项防控措施，防止疫情扩散蔓延，方便您在我院就诊，保障您和家人的健康，我们为您准备了这份特别的温馨提示，请您来院前仔细阅读。

**门诊时间和服务范围**

**自2020年****2****月****3****日起：****普通门诊正常开诊****（个别科室****除外****），****专病门诊、专家门诊、特需门诊暂停****（除个别外），****何时恢复另行通知****。**

**急诊、发热门诊****24****小时照常开诊。**

1．开诊范围 

       ●  普通门诊（除个别）开放（**详见下表**），其余普通门诊暂停，开诊时间另行通知。

   其中，口腔初诊、产科门诊、耳鼻咽喉头颈外科普通门诊无现场挂号或就诊当日APP挂号，**仅接受预约患者就诊**。

      

       ●   专科门诊：血透、腹透、PICC、造口、疑难造口、儿童造口、儿内科血液、儿内科哮喘专科门诊正常开诊，**其余专科门诊暂停**，开诊时间另行通知。

       

       ●   专家门诊：血液科、皮肤科、营养科、妇科、产科、儿内分泌科、儿血液肿瘤科专家门诊正常开诊，**其余专家门诊暂停**，开诊时间另行通知。

       ●    特需门诊：皮肤科日间特需门诊正常开诊，**其余特需门诊暂停**，开诊时间另行通知。

       ●    部分检查项目，如消化内镜、支气管镜、喉镜及肺功能检查均暂停，恢复时间另行通知。

       ●    健康管理中心暂停健康体检。

2．为避免门诊患者过多造成交叉感染，**请无紧急就诊需求的患者暂时不要到医院就诊。**已预约挂号且选择暂时不到医院就诊的患者，可通过原途径取消预约。

3．已经预约我院暂停检查项目的患者，工作人员会与您联系。如未接到我院电话，有疑问的，可致电预约申请单上的联系电话咨询。如您确定不再做此项检查，我院承诺您自付费之日起一年内**凭发票**均可来院办理退费。

4. 根据上海市疫情防控工作要求，**我院实行对所有来院人员一律测量体温的防控措施。**请您按照医院指示标识，从规定的出入口进入和离开医院。请您积极配合流行病学调查和健康询问，测量体温后有序进入。

5. **如您符合以下情况之一，请主动、如实告知工作人员，**并遵循医护人员建议，真实、完整地登记有关信息后，按照医院安排到指定地点就诊。

  （1）体温≥37.5℃；

  （2）2周内曾经途经湖北，或有湖北旅行、居住史；

  （3）或2周内曾经接触过前述地区疑似或确诊患者；

  （4）或2周内密切接触湖北以外地区的有发热、干咳、乏力、感冒等症状的患者，现在自身有类似症状；

  （5）身边人有聚集性发病，或与新型冠状病毒感染者有流行病学关联；

  （6）其他可疑不适症状

6. **请您来院务必佩戴口罩**；为了您和家人的安全，**请减少陪同人员数量，原则上一名儿童患者仅需一名成人陪护。**具有上述第5条情况之一者，请不要作为陪同人员来院。

出入口调整
**疫情期间，对门诊出入口及诊区设置进行如下调整：**

   来门诊就诊患者和家属请从控江路1665号门进入，完成流调、测温、预检后有序进入门诊诊区。

住院陪护及探视
**原则上请您尽量不要来院探视，以免交叉感染**

1.若来院探视，请遵守医院探视时间规定。探视时间：

   **10:00-12:00；16:00-18:00**

2.医院实行**“一人一陪护”**制度：家属凭医生开具的陪客证入病区陪护，每位住院患者至多允许一名家属陪护。

3.有以下情况，请勿来医院陪护、探视：

 （1）体温≥37.5℃；

 （2）2周内曾经途经湖北，或有湖北旅行、居住史；

 （3）或2周内曾经接触过前述地区疑似或确诊患者；

 （4）或2周内密切接触湖北以外地区的有发热、干咳、乏力、感冒等症状的患者，现在自身有类似症状；

 （5）身边人有聚集性发病，或与新型冠状病毒感染者有流行病学关联；

 （6）其他可疑不适症状

**请来院陪护、探视人员佩戴好口罩，注意洗手，做好个人相关防护措施。原则上，请您尽量不要来院探视，以免交叉污染。**
