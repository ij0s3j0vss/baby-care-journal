# “阳康”后带状疱疹更高发，接种疫苗可有效预防

> 更新时间：2026-09-17 (UTC+8)

最近一项发表在《Open Forum Infectious Diseases》（传染病开放论坛——美国传染病协会的期刊）的回顾性队列研究引发关注：**与未被确诊患有新冠的人群相比，美国50岁及以上的新冠患者患带状疱疹的风险更高**。

该研究针对的50岁以上的成年人——这一带状疱疹的高发人群。研究发现，与从未感染新冠病毒的对照组相比，研究组新冠病毒感染后6个月内患带状疱疹的风险高出**15%**，研究组中那些需要住院治疗的新冠重症患者罹患带状疱疹的风险高出**21%**。带状疱疹的发病与机体免疫功能的下降（至保护阈值以下）直接相关，而**新冠病毒的感染很可能导致阳过或阳康人群尤其是重点发病人群免疫功能的相对（于未感染人群）下降最终使得带状疱疹更高发。**

**什么是带状疱疹？**

它是由**水痘****-带状疱疹病毒**引起的**急性感染性皮肤病**。该病毒**可在人体内潜伏多年**，它有亲神经性，在人体经劳累、淋雨或感冒等诱因出现**免疫功能受损**时，这个病毒可能**重新激活**，沿神经纤维走行蔓延侵犯累及皮肤，导致受侵犯的神经和皮肤发生强烈的炎症；该病**引发的皮损是集簇性疱疹且伴有瘙痒灼痛感，多为单侧和按神经节段分布，呈带状分布**（一般不过身体中线），故得名“带状疱疹”。

带状疱疹虽然多出现在**抵抗力相对较差的中老年人**身上，但有些**年轻人**在熬夜疲劳、外伤、心理压力大等导致**抵抗力下降**的情况下也可能中招。起居有常，避免熬夜；饮食有节，尽量避免吃辛辣刺激的食物；锻炼适度，做好心理调适；这些都是**保持****好免疫功能的根本之道**。

带状疱疹一旦发病，不论是急性期疼痛及皮损，还是后遗神经痛等并发症，都严重影响患者的生活质量，疾病的医疗负担和社会负担很重。本身这个疾病“早发现”相对困难，治疗窗很窄，治疗手段相对有限，很多患者因为治疗不及时不规范而留有后遗神经痛的并发症。**要想远离这些困扰，最便利最有效的手段就是接种带状疱疹疫苗，做到未病先防。**

现在南方医院预防保健科开展带状疱疹疫苗接种，适用于**50岁及以上的成人**，尤其是老年人和**有恶性肿瘤、糖尿病、器官移植（服用抗排异药物）等慢性病或免疫功能缺损背景的患者推荐**接种带状疱疹疫苗；该疫苗是2剂次接种，接种间隔2-6个月。研究表明：**对****50岁以上人群该疫苗的保护效力可高达97.2%，保护期达20年以上。**
